# v1.0.1

本次更新新增 AI 自动采用项目工具链、macOS 原生桌面界面，并加固下载、解压、安装与卸载边界。CLI、GUI 与应用版本统一显示为 **v1.0.1**。

## 新增功能

### AI / Agent 自动使用项目版本

- `vsm run -- <命令> [参数...]`：读取项目版本声明，在对应工具链环境中执行命令，并透传退出码。
- `vsm run --install-missing -- <命令>`：补装缺失工具后执行，补装必须取得并验证发布方 SHA256。
- `vsm context --json`：只读输出项目要求、版本来源、解析版本、激活状态、覆盖冲突和建议命令；`--check` 可用作自动化检查。
- 设置 `VSM_NOTIFY=1`，可在终端版本组合发生变化时显示提示。

```bash
vsm context --json
vsm run -- go test ./...
vsm run -- node app.js
vsm run --install-missing -- go test ./...
```

### macOS 原生 GUI

- Universal `VSM.app` 同时支持 Apple Silicon 和 Intel，最低系统版本为 macOS 12.0。
- 应用内置 CLI，包含图标、原生菜单、红绿灯按钮留位及项目目录选择。
- 支持在 macOS 激活 shell 环境；长安装路径会自动省略显示，保持侧栏宽度。
- CLI、界面版本标识和应用标题使用统一版本来源。

### 开发体验

- `vsm doctor`：环境诊断。
- `vsm shell <工具> <版本>`：临时版本会话。
- `vsm completion <shell>`：bash、zsh、fish、PowerShell 补全。
- `vsm size` / `vsm clean`：空间统计与下载缓存清理。
- `list`、`list-all`、`current`、`detect`、`doctor`、`size`、`clean`、`context` 支持 JSON 输出。
- `vsm path-init` 支持 Windows、macOS 和 Linux。

## 安全与可靠性

- 解压统一采用目录边界约束，拒绝越界路径、越界链接、特殊设备及重复条目，限制展开体积与文件数量。
- 下载验证 HTTPS、响应长度、归档格式、分块区间及实体条件，失败时清理临时文件。
- Go / Node 使用官方 SHA256，GitHub Release 使用可用资产摘要，manifest 支持固定摘要。CLI 与 GUI 可要求缺少摘要时拒绝安装。
- 安装目录隔离、唯一暂存目录和跨盘就位保护；Windows 使用原生 API 创建目录联接。
- 自定义安装卸载同时校验独立记录、目标路径和随机令牌，纳管目录只删除链接。
- 版本文件拒绝指向所属目录外的链接，防止项目通过恶意链接读取私有文件。
- 发布包附带 `SHA256SUMS`，所有平台安装包验证齐全后才公开发布。

## 问题修复

- `.tool-versions` 更新保留注释、空行和 BOM，正确处理重复声明与读取失败。
- `vsm exec` 与 `vsm run` 保留子进程退出码。
- 退出项目后恢复原有 PATH、GOROOT、JAVA_HOME；重复切换不累积 PATH。
- 修复 shell 路径转义、Git Bash 路径转换和配置错误被忽略的问题。
- 修复 macOS GUI 链接失败及从 Finder 启动时项目目录识别问题。
- 修复 GUI 并发状态读取与长路径布局问题。

## 下载

- Windows：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`，GUI 为 `vsm-gui-windows-amd64.exe`。
- macOS：`vsm-darwin-amd64` / `vsm-darwin-arm64`，GUI 下载 `vsm-gui-macos-universal.zip`。
- Linux：`vsm-linux-amd64` / `vsm-linux-arm64`，GUI 为 `vsm-gui-linux-amd64`。

macOS 应用采用 ad-hoc 签名，尚未进行 Developer ID 签名与公证。复杂版本范围沿用现有匹配规则，建议在 `.tool-versions` 固定具体版本。详细说明见仓库中的 `docs/security.md` 和 `docs/agent-integration.md`。
