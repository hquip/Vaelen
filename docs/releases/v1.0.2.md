# v1.0.2

本次更新新增 MCP 服务和每项目独立环境，让 AI 读取项目要求、选择语言版本、安装工具并运行命令。CLI、GUI、Windows 文件版本与 macOS 应用版本统一为 **v1.0.2**。

## 新增功能

### MCP：AI 直接管理项目工具链

- `vsm mcp config --project <项目目录>`：生成客户端配置；GUI 也可生成并复制。
- `vsm mcp serve --project <项目目录>`：启动绑定该项目的 stdio 服务；可加 `--read-only`。
- 提供 7 个工具：`vsm_context`、`vsm_project_status`、`vsm_list`、`vsm_project_init`、`vsm_use`、`vsm_install`、`vsm_run`。
- AI 可读取结构化版本上下文、设置项目版本、安装缺失工具并执行命令。安装必须验证发布方 SHA256，MCP 安装仅允许写入本地项目环境。
- 支持结构化结果、退出码、超时、取消、输出限制和进程树清理；不开放网络监听端口。

### 一个项目，一个环境

| 模式 | 行为 |
| --- | --- |
| `local`（默认） | 项目独立安装目录、下载与工具缓存、Go/npm/pip/Cargo/Gradle 状态，以及按 Python 版本建立的 venv |
| `versions` | 共享已安装工具，按项目声明选择版本 |
| `docker` | 验证指定镜像中的语言版本，再使用同一镜像执行；仅挂载当前项目，根文件系统只读、禁止提权并限制进程数 |

```bash
cd my-app
vsm project init
vsm use go 1.25.11
vsm run --install-missing -- go test ./...
vsm context --json
vsm mcp config --project /absolute/path/to/my-app
```

Windows 生成配置示例：`vsm mcp config --project "D:\work\my-app"`。

项目配置保存在 `.vsm/project.json`，可与 `.tool-versions` 一起提交；运行时文件由 `.vsm/.gitignore` 排除。`local` 模式不继承父项目声明或全局默认语言版本，拒绝向项目外安装和纳管共享运行时，不持久修改系统 PATH。

### GUI 与 macOS

- 新增「隔离环境 / MCP」入口：初始化项目、选择隔离模式、指定 Docker 镜像，以及生成和复制 MCP 配置。
- 切换项目后同步更新工具状态；隔离模式引导使用 `vsm run` 执行项目命令。
- macOS 继续提供 Universal 原生界面，支持 Apple Silicon 与 Intel，应用内置 CLI，最低系统版本 macOS 12.0。

## 问题修复

- 修复 Go 检测受当前项目 `go.mod`、工具链自动下载和环境变量影响，出现版本错误或 `?` 的问题；优先读取安装本身的编译信息，失败时在独立探测环境中获取版本。
- 保留 Node/Python 项目常见版本范围，支持比较、组合、OR、caret、tilde 和通配符匹配，避免将 `<20` 等约束误当作版本。
- 执行选定 Go 时设置 `GOTOOLCHAIN=local`，避免工具链自动切换；Windows 显式调用 `go.exe` 同样检查项目要求。
- 卸载最后一个版本时清理残留 shim；空目录或损坏安装不再误报成功。
- 项目命令隔离继承的 Python/Node 搜索路径，按 Python 版本创建并复用 venv；缺少 venv 组件时明确报错。
- MCP 子进程在执行前重新检查项目模式，防止模式变化绕过安装边界。

## 验证与适用范围

验证覆盖 Windows、macOS、Linux 测试，Go race 检查、6 个 CLI 目标与 3 个 GUI 平台构建、真实 Docker 双项目隔离、真实 Python venv、macOS 应用启动，以及 MCP 官方 TypeScript SDK stdio 互通。

`local` 提供工具和依赖环境隔离，执行代码仍具有当前用户权限。Docker 模式需要运行中的 Docker Engine/Desktop，以及包含项目所需工具的镜像；多语言项目需使用合适的自定义镜像。当前不支持已有环境的自动模式迁移，复杂版本范围也不覆盖完整 PEP 440/SemVer 语法。

macOS 应用使用 ad-hoc 签名，尚未进行 Developer ID 签名与公证。

## 下载

- Windows：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`；GUI：`vsm-gui-windows-amd64.exe`。
- macOS：`vsm-darwin-amd64` / `vsm-darwin-arm64`；GUI：`vsm-gui-macos-universal.zip`。
- Linux：`vsm-linux-amd64` / `vsm-linux-arm64`；GUI：`vsm-gui-linux-amd64`。
- 发布包附带 `SHA256SUMS`。

详细用法见 [MCP 文档](https://github.com/hquip/Vaelen/blob/v1.0.2/docs/mcp.md) 和 [项目环境文档](https://github.com/hquip/Vaelen/blob/v1.0.2/docs/project-environments.md)。
