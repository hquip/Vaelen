# v1.0.3

本次正式发布整合 v1.0.2 之后的项目界面改进与多 AI 客户端接入，并修复 Docker 安装边界、Python venv 损坏回退、预发布版本排序和 MCP 安装超时问题。CLI、GUI、Windows 文件资源及 macOS 应用统一为 **v1.0.3**。

## 问题修复

- **Docker 工具只由镜像提供**：GUI、CLI 和底层安装器统一拒绝安装/纳管宿主机工具，在联网和创建安装目录之前返回错误。GUI 改为镜像工具视图，可直接保存项目的语言版本要求；不会把遗留的宿主机目录误显示成容器工具版本。
- **Python venv 损坏时停止执行**：检查配置、管理标记和 Python 入口；缺少入口会给出修复路径。项目运行只查找 venv 中的 Python，不再回退到基础解释器。已有依赖不会自动删除，可用项目同版本 Python 按原路径修复环境。
- **修正预发布版本选择**：rc / beta 低于对应正式版，预发布数字标识按数值比较，忽略构建元数据。普通数字前缀、`latest` 和未声明预发布版本的范围默认排除试用版；明确声明的预发布版本仍可使用。
- **MCP 安装超时可调**：`vsm_install` 新增 `timeout_seconds`，支持 1–600 秒，默认 600 秒。`vsm_run` 保留默认 120 秒；两者均校验超时范围，超时会终止子进程。客户端自身的调用时限仍然生效。

## 多 AI 客户端接入

新增 6 类客户端预设与通用预设：

- Cursor、Claude Desktop、Claude Code。
- Codex CLI / IDE / 桌面：生成 TOML。
- VS Code / GitHub Copilot：生成 `servers` JSON。
- Windsurf / Cascade，以及使用 `mcpServers` JSON 的通用客户端。

GUI 中选择客户端后，会显示保存位置和接入步骤，并生成对应格式。可选择只读模式，仅开放 3 个查看工具；普通模式保留 7 个工具。切换项目、客户端或只读模式会清空旧配置，避免误用。

```bash
vsm mcp config --project /path/to/app --client cursor
vsm mcp config --project /path/to/app --client codex
vsm mcp config --project /path/to/app --client vscode --read-only
```

安装工具时指定超时：

```json
{"name":"vsm_install","arguments":{"tool":"go","version":"1.25.11","timeout_seconds":600}}
```

## 项目界面改进

- 弹窗按「选择项目 → 配置环境 → 连接 AI」展示，提供明确的选择/更换项目按钮。
- 初始化后显示环境状态、语言版本入口和命令示例。
- 生成、复制 MCP 配置分成独立动作；错误直接显示在弹窗内，内容可滚动，标题和关闭按钮保持可见。
- 生成配置前检查 CLI 是否支持 MCP，旧版或缺失时提示更新；生成配置不会覆盖 AI 客户端设置。
- Windows、Linux 和 macOS 使用相同操作流程；macOS 继续提供内置 CLI 的 Universal 原生应用。

## 验证与范围

验证覆盖 Go race 测试和 vet、Docker 安装写入拒绝、真实 Python venv 的创建/损坏/修复、预发布版本比较与范围筛选、MCP 安装参数和实际超时终止、GUI 点击流程及 Windows/macOS 小窗口布局。多客户端配置已验证 JSON/TOML 解析，并由本机 Codex 和 Claude Code 在独立临时设置中读取。

项目 CI 覆盖三系统测试、真实 Docker 隔离、六目标 CLI 和三平台 GUI 构建，以及 macOS 应用实际启动。

本地隔离仍是工具与依赖环境隔离，运行代码具有当前用户权限；Docker 需要运行中的引擎和匹配工具链的镜像。复杂版本范围不覆盖完整 PEP 440 / SemVer 范围语法。当前 MCP 提供本地 stdio 传输，客户端配置需按提示合并并重新连接。

## 下载

- Windows：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`；GUI：`vsm-gui-windows-amd64.exe`。
- macOS：`vsm-darwin-amd64` / `vsm-darwin-arm64`；GUI：`vsm-gui-macos-universal.zip`。
- Linux：`vsm-linux-amd64` / `vsm-linux-arm64`；GUI：`vsm-gui-linux-amd64`。
- 发布包附带 `SHA256SUMS`。macOS 应用使用 ad-hoc 签名，未进行 Developer ID 签名和公证。

用法见 [MCP 接入](https://github.com/hquip/Vaelen/blob/v1.0.3/docs/mcp.md) 与 [项目环境](https://github.com/hquip/Vaelen/blob/v1.0.3/docs/project-environments.md)。
