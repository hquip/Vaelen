# v1.0.4

实现用户建议 [#7](https://github.com/hquip/Vaelen/issues/7)：新增 `vsm help <command>`，查看指定命令的详细用法、选项、说明与示例。CLI 与 GUI 版本统一为 **v1.0.4**。

## 命令详细帮助

```bash
vsm help install
vsm install --help
vsm help project init
vsm project init -h
vsm help mcp config
```

- 覆盖所有现有命令，以及 `project init`、`project status`、`mcp serve`、`mcp config` 子命令。
- 支持别名：例如 `vsm help i` 与 `vsm help install` 显示相同内容。
- 未指定主题时显示总览；未知命令、未知子命令或多余主题参数会显示提示并返回非零退出码。
- 帮助在环境初始化前返回，即使项目配置损坏或数据目录不可用也能查看，不会执行安装或修改配置。
- 保留子程序参数透传：`vsm run -- node --help` 和 `vsm exec node --help` 将帮助参数交给 Node；查看 VSM 自身用法可运行 `vsm help run` / `vsm help exec`。
- Bash、Zsh、Fish、PowerShell 的 `help` 参数补全提供命令名。

## 验证

新增回归测试覆盖所有命令帮助页、别名、常用帮助入口、错误退出码、损坏配置下的只读行为，以及真实子进程的帮助参数透传。本地 CLI race 测试与 vet 通过；发布继续由三平台构建、六目标 CLI 和 macOS 应用启动验证把关。

## 下载

- Windows：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`；GUI：`vsm-gui-windows-amd64.exe`。
- macOS：`vsm-darwin-amd64` / `vsm-darwin-arm64`；GUI：`vsm-gui-macos-universal.zip`。
- Linux：`vsm-linux-amd64` / `vsm-linux-arm64`；GUI：`vsm-gui-linux-amd64`。
- 所有安装包附带 `SHA256SUMS`。macOS 应用使用 ad-hoc 签名，未进行 Developer ID 签名与公证。
