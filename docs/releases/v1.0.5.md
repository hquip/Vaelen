# v1.0.5

修复用户反馈 [#10](https://github.com/hquip/Vaelen/issues/10) 的 Python 版本查询/安装 `unexpected EOF` 问题，完善网络配置与终端输出，并新增从官方 GitHub 更新 VSM 自身的功能。CLI、GUI 与原生应用版本统一为 **v1.0.5**。

## GitHub 自更新

```bash
vsm update --check
vsm update
vsm update --gui
vsm update --version v1.0.5 --check --json
```

- 从 `hquip/Vaelen` 官方稳定 Release 检查版本，按操作系统和架构选择资源；不自动降级。
- 验证官方 SHA256、下载长度与程序组件/平台，新 CLI 还会验证版本。全部组件准备完成后才替换；失败时尝试恢复旧程序。
- GUI 增加「检查 VSM 更新」，显示发布说明并支持下载更新。Windows/Linux 同步 GUI 与配套 CLI；macOS 整体更新 `.app`，验证 codesign 与内置 CLI，避免单独替换组件破坏应用签名。
- 更新仅更换 VSM 程序，保留语言安装、项目环境和 AI 客户端设置。完成后请重新启动。
- 程序目录需要可写。运行中的旧程序或 macOS 旧应用会按提示保留备份，退出后可手动删除；更新锁冲突或目录不可写时明确报错。

旧版没有该命令或入口，需要从 GitHub Releases 手动升级到本版本一次，之后即可使用内置更新。macOS 请先将应用移出只读磁盘映像。

## Python EOF 修复

- Python 上游单个发布包含近千个资源，原先每页 20 个发布可能超过 16 MiB 读取上限，JSON 被截断后只显示 `unexpected EOF`。
- 默认缩小到每页 5 个发布，超出上限继续自适应缩小，保留有界历史扫描。复用同进程短时间内的元数据，避免安装解析重复获取大列表。
- 明确区分超大响应与损坏/截断 JSON，对网络和读取错误重试，并附带请求地址和代理/镜像排查提示。
- 实际 GitHub 查询已成功返回 66 个 Python 版本。历史列表仍可能需要较多网络流量，速度取决于网络和代理。

## 网络与终端体验

```bash
vsm mirror set github https://mirror.example/
vsm mirror set github-api https://api-mirror.example/
vsm mirror set node https://mirror.example/node/
vsm mirror set npm https://registry.example/
vsm mirror list --json
vsm proxy socks5h://127.0.0.1:1080
vsm proxy --json
vsm current --all
```

镜像域名是格式示例，需换成自己的可用服务。支持 `go`、`node`、`npm`、`github` 与 `github-api` 独立源；`github` 使用完整 URL 代理前缀，其余替换上游基地址。`npm` 镜像通过项目命令的子进程环境生效，不改 `.npmrc`。

- 镜像支持查看、JSON 输出和删除单项；`off` 禁用镜像，`custom` 启用自定义源。
- 代理明确支持 HTTP、HTTPS、SOCKS5、SOCKS5H，拒绝未知协议，可查看当前配置或 JSON。
- 修复隔离项目中 GUI/CLI 的网络设置写入未使用位置的问题，统一写入实际生效的全局网络配置。
- `current` 默认隐藏未启用项，`--all` 可显示全部；终端支持 ANSI 时显示彩色工具和版本，JSON、重定向输出保持纯文本，支持 `NO_COLOR`。

发布方摘要及 VSM 自更新不使用自定义镜像作为可信来源。

## 下载

- Windows CLI：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`；GUI：`vsm-gui-windows-amd64.exe`。
- macOS CLI：`vsm-darwin-amd64` / `vsm-darwin-arm64`；GUI：`vsm-gui-macos-universal.zip`。
- Linux CLI：`vsm-linux-amd64` / `vsm-linux-arm64`；GUI：`vsm-gui-linux-amd64`。
- 附带 `SHA256SUMS`。macOS 应用仍使用 ad-hoc 签名，未进行 Developer ID 签名和公证。
