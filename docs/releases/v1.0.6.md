# v1.0.6

新增 CLI、GUI 与 MCP 统一的本地运行日志，方便排查安装、下载、版本设置、项目环境和自更新失败。CLI、GUI 与原生应用版本统一为 **v1.0.6**。

## 日志查看与导出

```bash
vsm logs                          # 最近 100 条记录
vsm logs --tail 200 --level error  # 最近 200 条错误
vsm logs --json                   # 结构化输出
vsm logs path                     # 日志目录
vsm logs export vsm-report.jsonl   # 导出全部保留日志到新文件
vsm logs clear                    # 仅清理 VSM 日志
vsm help logs
```

GUI 左下角新增「日志」入口，支持最低级别筛选、刷新、系统文件对话框导出与清理确认。Windows、macOS、Linux 使用同一套日志，项目隔离模式不改变日志位置。配置损坏时仍可进入日志功能。

## 记录内容与保存策略

- 记录操作开始、结束、耗时、退出码、工具版本、下载重试、网络错误及版本探测失败；每条记录带 UTC 时间、组件、进程 ID 和 VSM 版本。
- 默认记录 `info` 及以上；启动前设置 `VSM_LOG_LEVEL=debug|info|warn|error|off` 可调整级别。`debug` 额外记录 HTTP 状态和成功版本探测，`off` 停止新增日志。
- 全局保存到 `~/.vsm/logs`，设置 `VSM_HOME` 时保存到 `VSM_HOME/logs`。主日志每 2 MiB 轮换，保留 3 个备份，总计最多约 8 MiB。
- 使用系统文件锁协调多进程写入、轮换与清理；进程异常退出后锁自动释放，半条记录不会吞掉下一条完整日志。
- 日志不可写时不改变业务操作结果；查看、导出、清理失败会明确提示。导出不覆盖已有文件，清理仅删除已知日志文件。

## 隐私与输出兼容

日志仅保存在本机，不自动上传。不记录完整命令参数、环境变量转储、子进程输出或 MCP 请求/返回正文。URL 用户名密码、完整查询字符串、片段和常见密码/密钥字段会脱敏。错误中可能包含本地路径，分享导出文件前可检查。

日志不写入标准输出或标准错误，不干扰命令 JSON、shell 激活脚本和 MCP 协议。帮助、版本查询与日志管理不记录自身；每次提示符触发的成功 `env` 调用仅在 `debug` 下记录。

详细使用方法见 [日志说明](../logging.md)。

## 升级

已安装 v1.0.5 的用户可从官方 GitHub Release 更新：

```bash
vsm update --check
vsm update
vsm update --gui  # Windows/Linux 同步更新相邻 GUI
```

也可在 GUI 点击「检查 VSM 更新」，更新完成后重新启动。Windows 下载使用时，请将 CLI 改名为 `vsm.exe`，与 GUI 放在同一目录。更早版本没有更新入口时需手动下载。

## 验证与下载

覆盖多进程/多 goroutine 写入、轮换容量、崩溃残行恢复、导出防覆盖、清理边界、凭据脱敏、日志写入失败、MCP 正文隔离，以及 GUI 筛选、导出、失败重试和清理确认。沿用三系统测试、六目标 CLI、三平台 GUI 和 macOS 实际启动验证。

- Windows CLI：`vsm-windows-amd64.exe` / `vsm-windows-arm64.exe`；GUI：`vsm-gui-windows-amd64.exe`。
- macOS CLI：`vsm-darwin-amd64` / `vsm-darwin-arm64`；GUI：`vsm-gui-macos-universal.zip`（Intel / Apple Silicon，macOS 12+，内置 CLI）。
- Linux CLI：`vsm-linux-amd64` / `vsm-linux-arm64`；GUI：`vsm-gui-linux-amd64`。
- 附带 `SHA256SUMS`。
