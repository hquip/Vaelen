# v1.0.7

修复从 GitHub 更新 VSM 时没有下载进度的问题。CLI、GUI 与原生应用版本统一为 **v1.0.7**，包含 v1.0.6 的本地日志功能。

## 实时更新进度

- GUI 显示整体百分比、已下载/总大小、下载速度、当前文件和文件序号；Windows/Linux 更新 GUI 与 CLI 时按所有文件总大小计算，macOS 显示整个通用应用包进度。
- 下载中持续读取字节并发送进度，无需等整个响应读取完成；界面刷新有节流。
- 收不到新数据时显示等待网络数据的时间，重试时显示第几次尝试并重置当前文件计数。
- 区分检查版本、下载、SHA256 校验、解压、程序/签名验证和替换阶段。下载达到 100% 后仍会继续验证，只有替换成功才提示更新完成。
- CLI 在标准错误显示进度和速度；`--json` 保持单个结构化结果，不混入进度文本。
- 延续原有完整性校验、取消/超时和失败回滚机制，校验失败不会替换旧程序。

## 升级

在 GUI 点击「检查 VSM 更新」，或使用：

```bash
vsm update --check
vsm update
vsm update --gui  # Windows/Linux 同步更新相邻 GUI
```

新界面会在升级并重新启动到 v1.0.7 后生效；正在运行的旧程序仍使用原来的更新窗口。

## 日志

本版本也包含 v1.0.6 的统一本地日志。GUI 左下角点击「日志」，或运行 `vsm logs` / `vsm logs --level error` / `vsm logs export vsm-report.jsonl`，可查看、筛选和导出诊断信息。详见[日志说明](https://github.com/hquip/Vaelen/blob/v1.0.7/docs/logging.md)。

## 验证与下载

覆盖传输未结束时实时报告、断流重试、上下文取消、整体字节计数、校验失败不替换，以及 GUI 下载/等待/重试/校验/完成/失败状态与小窗口布局。沿用三系统测试、六目标 CLI、三平台 GUI 和 macOS 实际启动验证。

提供 Windows、macOS、Linux 的 6 个 CLI 包、3 个 GUI 包和 `SHA256SUMS`。macOS GUI 同时支持 Intel / Apple Silicon，最低 macOS 12。
