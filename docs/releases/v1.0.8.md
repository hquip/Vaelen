# v1.0.8

优化用户反馈 [#12](https://github.com/hquip/Vaelen/issues/12) 的 JDK 下载缓慢问题，修复 Java 镜像未生效，完善 4 连接分块下载与任务内续传。CLI、GUI 与原生应用版本统一为 **v1.0.8**。

## JDK 下载加速

```bash
vsm mirror cn
vsm install java 21 --require-checksum
```

GUI 顶部选择「镜像：国内」后安装 Java，行为相同。

- 改为从 Adoptium 官方 GA 接口一次获取具体 Temurin 安装包 URL、大小和 SHA256，避免动态地址多次跳转及 URL/摘要来自不同 latest 快照。
- 国内模式直接使用清华 Adoptium 镜像。镜像缺包、返回错误或摘要不匹配时，回退同一官方文件；始终使用原发布方 SHA256 校验。
- 新增独立 `java` 自定义镜像源：`vsm mirror set java https://mirror.example/Adoptium/`。镜像根目录结构为 `<major>/jdk/<arch>/<os>/<filename>`；示例域名需替换为实际服务。
- `vsm mirror off` 关闭所有镜像。官方完整性元数据仍从原站获取。

## 分块下载与失败恢复

- 大包有强 ETag 或官方 SHA256，且服务器支持 Range 时使用 4 连接并行。
- HEAD 不支持或漏报分块能力时，发送 1 字节 Range 请求验证，避免直接退回单连接。
- 分块断流时，从该分块已接收的偏移继续请求，不重下已完成的分块；共用连接池。一块不可恢复地失败后，取消其它请求，再决定回退。
- 严格检查每次响应的 Content-Range、长度、ETag 与内容编码。整包 SHA256 通过后才解压。
- 下载进度增加速度显示。源站不支持 Range 或缺少校验依据时保持单连接。

续传仅在同一次下载任务内生效，暂不支持关闭程序后继续。实际速度取决于网络、限速和镜像同步情况；不承诺固定提速倍数。详情见 [JDK 下载说明](https://github.com/hquip/Vaelen/blob/v1.0.8/docs/jdk-downloads.md)。

## macOS Java 修复

识别 Temurin 应用包中的 `Contents/Home/bin`，正确设置 `JAVA_HOME` 为 `Contents/Home`，避免下载完成后找不到 Java。

## 升级

在 GUI 点击「检查 VSM 更新」，或使用：

```bash
vsm update --check
vsm update
vsm update --gui  # Windows/Linux 同步更新相邻 GUI
```

升级后重新启动。Windows 手动下载时，请将 CLI 改名为 `vsm.exe`，与 GUI 放在同一目录。本版包含此前的实时更新进度和本地日志功能；原有语言安装和项目配置保留。

## 验证与下载

覆盖 Windows/macOS/Linux 安装包元数据选择、GA 限定、镜像映射/关闭/自定义优先级、无 HEAD/ETag 分块、断流续传、连接取消、错误镜像回退、SHA256 失败不留残包及 macOS Java 路径。已实际验证官方三平台元数据与清华镜像 4 路 Range 样本，未以样本推算整包速度。

提供 Windows、macOS、Linux 的 6 个 CLI 包、3 个 GUI 包与 `SHA256SUMS`。macOS GUI 为 Intel / Apple Silicon 通用应用，最低 macOS 12。
