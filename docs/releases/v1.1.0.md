# v1.1.0

新增项目工作台，把工具链锁定、项目变量、任务执行和 AI 管理接到同一配置上。

- `vsm.json` 声明工具、dotenv、变量及命名任务，拒绝歧义配置、危险变量和越界路径。
- `vsm.lock` 固定具体构建、各平台包和官方 SHA256，支持 `install --locked` / `run --locked`，校验安装来源与定义变更。
- 任务支持依赖图、并行、输入/输出内容缓存、超时取消、进程树清理与退出码透传。
- GUI 项目工作台提供配置编辑和修复、检查后信任、多平台锁定、锁定安装、任务运行/停止和工具目录。
- 通用 GitHub 后端匹配归档或原生可执行文件，支持命令名、子目录和资产筛选；不唯一或无摘要时拒绝安装。
- Java 支持 Temurin 精确构建与 Zulu 官方来源，Zig 增加官方摘要。
- MCP 扩展为 14 个工具（7 个只读），提供锁文件、目录、任务查询与执行，不能自行授予信任。
- 从 mise 的当前工具 JSON 预览导入，不覆盖已有配置，不复制任务或秘密变量。
- 提供 Windows 与 macOS/Linux 安装脚本，验证 SHA256、备份和失败恢复。
- 任务缓存按锁定模式、实际工具版本与构建来源区分，采用与执行一致的项目边界；Docker 任务始终执行。
- 配置信任与文件缓存摘要采用无歧义的文件边界；环境文件变更撤销信任。修复大量中文任务输出导致 MCP 服务退出，以及移除工具来源后无法更新锁文件的问题。

已有版本可运行 `vsm update --gui`，同步更新 CLI 和 GUI。Windows 手动下载时，将对应 CLI 改名为 `vsm.exe` 并与 GUI 放在同一目录；macOS 通用应用已内置 CLI，支持 Apple Silicon 和 Intel。

使用方法和明确边界见 [项目工作台](https://github.com/hquip/Vaelen/blob/v1.1.0/docs/workspaces.md)。本地环境隔离不等同于系统沙箱，任务缓存不等同于远程缓存。
