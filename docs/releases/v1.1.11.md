# v1.1.11

修复 [Issue #35](https://github.com/hquip/Vaelen/issues/35) 的 Go / Lua 版本读取问题，以及 [Issue #36](https://github.com/hquip/Vaelen/issues/36) 的重复版本条目和安装路径歧义。修复已在 [PR #37](https://github.com/hquip/Vaelen/pull/37) 合并。

## 修复与改进

- **Lua / LuaJIT 探测参数**：使用只读的 `-v` 参数，识别标准输出或错误输出中的语言版本横幅；不再尝试将 `version` 当作脚本文件运行。
- **Go 发行版兼容**：构建元数据与命令回退支持 `+` 后缀、实验标记和 gccgo 附加信息，保留项目工具链自动切换隔离；命令执行验证复用相同解析器。不能识别时显示实际版本标识，不从报错中的数字猜测版本。
- **安装位置统一处理**：选择当前安装根目录或当前工具目录时使用默认位置。例如根目录为 `J:\vsm` 时，选择 `J:\vsm` 或 `J:\vsm\go`，Go 1.27.3 都安装到 `J:\vsm\go\1.27.3`，不会再生成 `go\go\1.27.3`。
- **提前拒绝无效嵌套**：其它嵌套在版本查找目录内的安装父目录会在查询远端或下载前被拒绝，目录别名也经过同样校验。单次自定义位置仍支持外部父目录，并自动创建 `工具名/版本`。
- **保留已有安装**：根据匹配的所有权记录，将旧版产生的存储文件夹从版本列表排除，并禁止作为版本整体卸载。原版本链接保持可用；卸载具体版本时保留其它安装，仅清理对应目标和空出的存储父目录。真实的自定义版本别名不受影响。
- **GUI 路径预览与日志**：界面显示实际安装路径，明确说明选择的是父目录；无效选择保留之前的有效位置。日志新增 `core · install.location`，记录注册入口与真实目标，方便排查。

## 更新

在 GUI 点击「检查 VSM 更新」，完成后重启；GUI 更新会一并处理配套 CLI，无需再单独下载。macOS `.app` 包含 CLI。

也可使用：

```bash
vsm update --gui
```

只使用命令行时运行 `vsm update`。手动替换 Windows / Linux GUI 文件时，使用同版本的配套 CLI。

升级后点击「系统检测 → 重新检测」。已有嵌套安装不需要搬迁或重装；如果之前误将 `go` 或 `java` 存储文件夹设为全局版本，请重新选择列表中的真实版本号。

## 验证与安装包

修复提交的 18 项 CI 检查全部通过，包含三系统测试、六目标 CLI、三平台 GUI、macOS 应用实际启动，以及 Docker / 原生数据库集成。Linux 使用真实 Lua 5.4 验证系统发现。本地完成完整 race 回归、`go vet` 和 Windows / macOS 外观下的 GUI 点击验证；覆盖双版本嵌套安装的卸载保护、目录别名、项目边界与提前校验。

提供 6 个 CLI 包、3 个 GUI 包与 `SHA256SUMS`。macOS GUI 同时支持 Intel / Apple Silicon，最低 macOS 12。
