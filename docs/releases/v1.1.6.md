# v1.1.6

下载默认优先使用可用本机代理；没有代理时使用国内源，并保留官方回退与 SHA256 校验。

## 自动选择网络

- 保留手动代理、`VSM_PROXY` 和强制直连设置。未配置时依次使用代理环境变量、Windows/macOS 系统中的本机代理、常见本机 HTTP/SOCKS5 端口。
- 自动探测只连接本机地址，并验证 HTTP CONNECT 或 SOCKS5 隧道；仅端口打开不视为可用代理。探测有超时且短暂缓存，不写系统代理设置。
- 新增默认镜像模式 `auto`：有代理时访问官方源，无代理时使用国内源。可继续手动选择 `cn`、`custom` 或 `off`。
- VSM 更新包无代理时尝试 ghfast.top / gh-proxy.com，失败后回退官方；自定义 GitHub 下载前缀继续受支持。GitHub 国内下载服务属于第三方，版本元数据和发布方摘要仍从官方获取。
- 代理出口访问官方更新 API 返回 403/429 时，版本元数据回退官方直连，程序包继续使用代理。
- GUI 显示当前检测到的代理，增加「自动检测」入口；下载进度和 CLI 输出区分本机代理、环境变量代理、国内源及官方 CDN。

## 完整性与回退

继续保留四连接分块、任务内续传、停滞超时和替换回滚。国内源返回网页、异常长度或错误区间时切换来源；完整包的 SHA256 不匹配时重新下载官方文件，仍不匹配则拒绝替换。镜像提供的摘要不能覆盖官方值。

## 更新

```bash
vsm update --gui
vsm proxy system
vsm mirror auto
```

GUI 的代理输入留空或点击「自动检测」，镜像选择「自动」。已有手动代理/关闭镜像配置会保留。

**首次升级仍由旧更新器执行**：旧版若未识别本机代理，可临时在 GUI「代理」中填写自己正在使用的本机地址，或从本发布页手动下载同版本 CLI 和 GUI。升级后可清空代理输入恢复自动选择；Windows CLI 与 GUI 放在同一目录，macOS 应用内置 CLI。

## 验证

测试覆盖本机 HTTP/SOCKS5 探测、普通服务误判、HTTPS 实际穿过代理、手动与 NO_PROXY 覆盖、镜像到官方的失败回退、两源损坏拒绝落盘、官方 API 403 回退，以及 Windows/macOS 小窗口界面。实网中自动识别本机 Clash 后，8.3 MiB 官方 CLI 从查询到下载、SHA256 和版本验证完成用时约 6.3 秒；这是当次网络测量，不代表固定速度。国内源回退由受控服务测试验证。
