# v1.2.0

语言目录从 78 项扩展到 **151 项工具链 / 工具**，配置自动安装来源的工具从 17 项增加到 **30 项**，并加入 **17 项宿主接入说明**。这些是工具、实现和接入入口的数量，不等于独立语言数量或所有语言均可自动安装。

## 新增语言与 SDK

- C/C++ 对应 GCC、Clang、MSVC 或 Zig；C#/F#/VB.NET 共用 .NET SDK。
- 扩充 Fortran、Ada、COBOL、BASIC、Pascal、Lisp/Scheme、Prolog、汇编、硬件和着色器工具链，以及 GDScript、Cairo、Move、J、BQN、Rebol、Hare、Hylo、Eiffel、Pharo、Squeak、MATLAB、NetLogo、Delphi 等入口。
- 新增 .NET、Dart、Julia、Flutter、PowerShell、Godot、Vyper、Arturo、Factor、Nim、Haxe、Scarb、Aptos 安装来源；按实际系统、架构和发行包决定能力。
- Red、Vale、Kona/K、UCBLogo 可手动提供版本标识后纳管；VSM 仅核验命令路径，不宣称已自动读取软件版本。

## 宿主接入

VBA、ABAP、Verse、PLC、AngelScript、Scratch、Snap!、Wolfram Language、SAS、Stata、LabVIEW、VB6、易语言、PL/SQL、T-SQL、Dyalog APL、kdb+/Q 提供宿主要求、接入步骤和官方说明。GUI 单独展示这些入口，不提供虚假的全局版本或安装按钮。

```bash
vsm tools search "C#"
vsm tools search Move --json
vsm tools info vba
vsm tools info abap --json
vsm adopt red --path /opt/red --name 0.6.6
```

## 探测、环境与校验

- 微软 SDK 使用官方 SHA512；严格校验、锁文件、下载及来源记录同步支持 SHA256/SHA512。Haxe 部分历史版本缺少摘要，严格模式会拒绝。
- .NET 支持 global.json 的 sdk.version，探测隔离项目选择。本地项目新增 NuGet/.NET、Pub、Julia、Scarb 缓存隔离。
- MATLAB/NetLogo 只读版本元数据，避免探测时启动大型软件或授权会话；终端诊断注明验证方式。Pharo/Squeak 的 VM 和 image 分开管理。
- J 探测避免启动 JDK 同名 jconsole；Erlang 忽略用户初始化和附加参数，MSVC 使用只读版本横幅，Flutter 仅读取已有缓存。
- Godot 保留 macOS 原签名应用包，Windows/Linux 提供固定命令；Vyper 验证二进制架构；Nim 使用官网稳定包，校验附件缺失时读取官方资产摘要；Arturo 默认 mini 命令行包。
- GUI/CLI 显示真实安装、纳管和平台限制。外部 manifest 可补充语言标签、说明、平台、版本规则，以及需要用户标注版本的本机工具。

MATLAB、Delphi 等 SDK 的授权、工具包及运行/编译条件由用户提供；本版本不修改 Office/SAP、数据库、系统 COM 注册或设备固件。详细能力、平台与验证边界见 [语言覆盖说明](../language-support.md)。

Windows 升级时请同时更新 GUI 与配套 CLI；内置更新入口可以一起更新。macOS 提供 Intel / Apple Silicon 通用应用。
