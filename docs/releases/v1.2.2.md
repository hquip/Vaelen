# v1.2.2

本版本修复 GitHub Issues #41、#42，并优化 GUI 项目入口。

## Maven 激活修复

- Maven 执行时自动解析当前目录对应的 Java 版本。
- 将所选 Java 的 `JAVA_HOME` 和 bin 目录注入 Maven 子进程，避免 `mvn.cmd` 报 `JAVA_HOME environment variable is not defined correctly`。
- 项目环境和直接 shim 执行使用同一套 Java 解析规则。

## Windows 探测修复

- 不再把 Windows `System32\\bash.exe` 的 WSL 启动器识别为 Bash 运行时。
- 不再把 JDK 的 `jconsole.exe` 识别为 J 语言引擎。
- 支持解码直接写入管道的 UTF-16 版本输出。
- nvm 没有激活 Node 版本时，显示明确的 `nvm use <版本>` 操作提示。

## GUI 优化

- 「项目环境与 AI」改为三张功能卡片：隔离环境 / MCP、项目工作台、数据库版本 / 实例。
- 增加功能图标、简短说明、悬停反馈和箭头；窄窗口自动收缩说明文字。
- 原有点击入口、后端接口和 macOS 布局保持兼容。

Windows、macOS、Linux 的 CLI 和 GUI 版本统一为 **v1.2.2**。完整测试、竞态检测、`go vet`、三平台构建和数据库/Docker 检查均通过。
