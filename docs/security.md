# 下载、安装与环境安全边界

保护对象是远端元数据、归档内路径和链接、命令参数以及可能损坏的本地配置。VSM 以当前用户权限运行，不是工具执行沙箱；用户主动信任的插件、下载源以及具有同等操作系统权限的程序仍属于信任边界。

## 解压

ZIP、tar.gz 和 tar.xz 最终统一使用 Go `os.Root` 下的文件操作。路径中拒绝绝对路径、`..`、Windows 驱动器/ADS、设备名称、控制字符和不可移植的特殊名称；链接只允许相对且词法上仍位于归档根目录，后续文件访问也受 `os.Root` 约束。
普通文件通过独占创建写入，已有链接、硬链接及重复条目不能被覆盖。设备、FIFO 等特殊条目直接报错，链接创建失败不静默忽略。
实现依据：[Go 的目录边界 API](https://go.dev/blog/osroot)。

默认限制：100,000 个条目、单文件 4 GiB、总展开量 16 GiB。可通过核心 `ExtractWithLimits` 指定更小限制。归档权限不会保留 setuid/setgid 等特殊位。

tar.xz 使用 `xz -dc`，或 macOS/Windows 的 bsdtar `@archive` 包含功能，将内容转换为 tar 流，外部工具不负责向安装目录解压。Linux 需要 xz；缺少兼容解码器时明确失败。解码进程有超时，不回退到无边界限制的落盘解压。

## 传输与完整性

- 远端资源要求 HTTPS，拒绝 HTTPS 降级重定向、URL 中的用户名/密码和过多重定向。允许 loopback HTTP；必须使用远端 HTTP 的用户可显式设置 `VSM_ALLOW_INSECURE_HTTP=1`。
- 下载限制为 8 GiB，使用独立临时文件，完成后按归档魔数确认格式并更名；失败临时文件会清理，HTML/错误页不会被作为工具安装。
- 有强 ETag 的大文件才启用并行 Range；每块使用实体条件并检查精确 Content-Range 和响应长度，限定写入范围。服务器行为不符合预期时回退单连接完整下载。
- Go / Node 的 SHA256 元数据从官方地址获取，不随下载镜像改写；GitHub Release 使用 API 提供的资产摘要。manifest 可通过 `checksums` 固定 `version/os/arch` 的摘要。
- 获取已配置校验来源失败、摘要格式错误或内容不匹配时停止安装。不匹配的缓存删除。发布方没有摘要时默认明确提示；`--require-checksum`、GUI 选项或 `VSM_REQUIRE_CHECKSUM=1` 可要求拒绝安装。

SHA256 能验证与所取元数据的一致性；这里没有实现发布者签名、公钥固定或透明日志验证。无摘要模式也不提供与严格校验相同的保障。

manifest 示例字段：

```json
"checksums": {
  "1.2.3/linux/amd64": "填入发布方的64位十六进制SHA256"
}
```

## 安装、链接与卸载

工具和版本必须为单个可移植标识符；拒绝路径分隔符、设备名和点目录。工具父目录不能是符号链接或 junction，只有具体版本允许链接到外部安装。
Windows junction 通过原生 API 创建，不经过 cmd.exe，路径中的 `%TEMP%`、`&` 等字符不会被展开或执行。
shims、downloads 与安装根目录相互隔离，安装根不能是磁盘根目录、包含 VSM_HOME 或覆盖管理目录。

跨盘安装使用唯一临时目录，全部复制成功后再就位；失败的暂存目录不会出现在已安装版本中。复制保持安全的相对符号链接并拒绝向源目录外读取。自定义安装不会覆盖已有目录。

`--path` 安装会生成随机令牌，同时写入安装目录标记和 registry 侧独立记录。卸载时校验工具、版本、目标路径及令牌；只有匹配的自定义安装才删除真实目录。单独伪造 `.vsm-install` 文件不构成删除授权。纳管版本只删除链接。
旧版本仅有标记、没有独立记录的外部安装采用保守策略：移除链接并保留真实文件，可由用户确认后手动清理。

配置写入使用临时文件、同步和替换，并保留原文件权限。读取错误必须返回，不能当作空文件覆盖；这不等同于多个进程对配置进行事务合并。
项目版本声明的读取也受对应目录边界约束，拒绝指向目录外的文件链接，避免仓库中的恶意链接把用户私有文件当作版本配置读取并输出。内部链接仍可使用；跨目录共享配置需改为项目内的声明文件。

## 环境切换

完整方案先验证工具目录、插件 bin 路径、环境变量名称与冲突，再输出 shell 脚本。遇到配置或解析错误时，`vsm env` 返回非零并输出基础环境恢复脚本，避免留下上个项目的版本。
调用方若自行调用 `vsm env`，应应用该恢复脚本并检查退出状态；shell hook 会在下一次提示符/目录切换时重新计算。

环境与 Agent 上下文的不变量和使用方式见 [Agent 接入说明](agent-integration.md)。
